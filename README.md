# My Portfolio

A personal portfolio website built using HTML, CSS, JavaScript,
Node.js, Express, EJS and MySQL.

## Features

- Home
- About
- Skills
- Projects
- Contact
- Admin dashboard
- Project management
- Contact messages

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- EJS
- MySQL

## Installation

```bash
npm install
